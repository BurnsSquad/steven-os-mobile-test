# Original Overview parent Finance summary — v147

The preserved original Overview dashboard now includes a separate Current Finance card. It reads the latest updated saved household paycheck plan through the existing authenticated parent Finance transport and asks the server to preview those saved inputs against current sources. It does not change plans, confirm facts, approve anything or send money.

The card distinguishes no saved plan, draft, saved approval, changed source fingerprint, current blockers and unavailable checks. Amounts are shown only when the current source fingerprint matches and the server returns no blockers. Those amounts are explicitly the current recalculation of saved inputs, including the parent-entered cash snapshot date—not a live bank balance. An old approval does not approve new source facts. The current check time is shown in 12-hour Eastern time.

Review latest paycheck plan opens that saved plan in the original Finance workbench and recalculates it through the existing review flow. It does not restore an unrelated unsaved draft over the selected plan. Missing plans and request failures are explained without manufacturing a new plan. With no saved plan, Open Finance review opens the checklist and current inputs.

The card is restricted to adult context and uses existing Finance RLS; no new access to the owner's private original workspace is granted to other adults or children. Other parents retain their existing shared Finance Center access. The card has no browser storage, no raw HTML interpolation of record names and no new iframe network capability. Original graphs remain historical/private, and summary data is not written into original private arrays or recovery files. Clear/navigation suppresses late results; the visible Overview refreshes through the existing 15-second original integration timer.

Validation: synthetic summary browser test covers empty state, latest selection, draft/approval labels, changed sources, blockers, failed checks hiding amounts, literal names, no child requests, read-only commands and clearing while a response is pending. Original private-source browser tests exercise the overview card and saved-plan navigation plus existing eleven-tab/five-calendar-view, shared planner, Finance/mobile/private export/recovery checks. Shared planner and two-parent Finance mock regressions also run. No new real-password/device acceptance or current financial confirmation is claimed.
