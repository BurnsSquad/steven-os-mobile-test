# Parent Finance review guide — v146

Current Finance now starts with a review checklist in the original Finance tab and shared Finance Center. Dad and Mom use the same existing parent-only workbench; no new role grants or tables are introduced.

The guide counts current editable non-inactive facts and flags reference/unconfirmed sources, unresolved confirmation items and incomplete dated-bill fields. Bill checks include exact-cent amount, due-date presence, household spending-account match, date certainty, payment state and a date for any claimed cash-snapshot deduction. This is a navigation aid, not a complete audit or an approval decision. Zero source flags does not prove the household has entered every obligation or supplied current cash.

Expand Facts needing review and select Review this fact to open the existing versioned review form. The parent must supply evidence/context, effective date and an explicit confirmation before saving a confirmed revision. Opening the guide or selecting a fact performs no financial write. Revised facts refresh the queue through the existing authenticated transport.

Go to paycheck inputs focuses the current plan form without resetting typed inputs. Follow the four steps: review facts, supply one current usable cash snapshot, review obligations/living/buffer and preview, then save a draft for review and optionally approve. Older imported balances are never automatically copied into the cash snapshot. Server calculation and version/source guards remain authoritative; no payment is sent.

The guide lives inside the existing self-contained workbench so the original opaque iframe uses the same behavior. No private source data is included in deployed assets. Existing original charts/layout and owner-only recovery boundaries remain unchanged. Sign-out/clear removes the guide's record-derived content.

Validation: two-parent synthetic browser test covers initial queue, navigation with no writes, unchecked confirmation, input focus, queue update after an unconfirmed bill, draft/approval/stale revision and mobile checks. Original private-source browser regression checks cover eleven tabs, five calendar views, Finance bridge/draft inputs, overlays, mobile and recovery exports. These are mocked checks, not a new claim of real family-device acceptance.
